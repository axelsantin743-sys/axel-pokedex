# Pokédex

Bienvenue sur **Pokédex**, une application permettant de découvrir les Pokémon et leurs informations principales.

## Fonctionnalités

- Consulter la liste des Pokémon
- Rechercher un Pokémon par son nom
- Afficher les types, statistiques et caractéristiques
- Naviguer facilement entre les différentes fiches

## Installation

1. Cloner le dépôt :

	```bash
	git clone <url-du-depot>
	```

2. Accéder au dossier du projet :

	```bash
	cd axel-pokedex
	```

3. Installer les dépendances si nécessaire :

	```bash
	npm install
	```

4. Lancer le projet :

	```bash
	npm run dev
	```

## Utilisation

Ouvrez l’adresse indiquée par le serveur de développement dans votre navigateur, puis recherchez un Pokémon ou parcourez la liste disponible.
